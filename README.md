## The entry

`main.py` writes exactly one letter to `/output/entry.txt`: **J**.

J is for **jittery** — a caffeine-fuelled day of hunting, building and
chasing deadlines, hands buzzing and brain still going. Vivid, funny,
and true.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output file contains exactly one character, `J`, with nothing else:
no word, no gloss, no punctuation, no trailing newline.
